# 手臂 1 新版鏡頭懸停驗證

流程已改為 Home_A → 停穩 → GetPickTarget → 物體上方停住。
`vision_test` 接受鏡頭從多顆藍色瓶蓋選出的單一目標，懸停點使用鏡頭 X/Y 與
`pick_z + approach_height`，不自動回 Home_A。

- 五個 ROS 2 套件建置成功，輸出保存在 `validation/vision_hover/build.log`。
- 主控測試 111 項通過（`validation/vision_hover/unit_tests.xml`），涵蓋目標有效性、座標範圍、高度、無目標、服務逾時、取消及單次 Home_A 行為。
- 新版鏡頭既有測試 85 項通過；在建置區副本執行，避免寫入唯讀原始碼。
- 真實 MoveIt 與模擬 CM530/視覺完成懸停；狀態為 MOVING_HOME_A、WAITING_FOR_VISION、MOVING_ABOVE_A、SUCCEEDED。
- 目標 `[0.15, 0.04, 0.04]` m，模擬關節經 FK 計算 TCP 為 `[0.149835, 0.040025, 0.040045]` m；完成後觀察 2 秒，位置維持不變。
- 鏡頭資料夾 70 個檔案的 SHA-256 前後一致；主控介面鏡像與新版定義一致。

模擬結果見 [simulation.json](validation/vision_hover/simulation.json)。
首次模擬受沙盒網路介面權限限制，後於沙盒外使用隔離 ROS domain 164、固定 demo 模式通過。
測試結束以 SIGINT 關閉 ROS 程序，部分節點記錄 KeyboardInterrupt；以上到位結果取自關閉前。
未連接真實相機與馬達，實機仍須使用量測的 Home_A、TCP、homography 及高度設定驗收。

操作方式見 [鏡頭座標運動測試](手臂1鏡頭座標運動測試.md)。
